## The Ultimate Stack (2026)

### Core (100% Open Source / MIT)
- **Build**: Vite 6 + React 19 + TypeScript + Tailwind v4
- **3D**: Three.js r175+ · `@react-three/fiber` v9 · `@react-three/drei` · `@react-three/postprocessing` · `@react-three/rapier`
- **Design**: `@splinetool/react-spline` (visual luxury authoring)
- **Motion**: `motion` (Framer Motion successor) — spring physics for UI + 3D hybrids
- **GPU Intelligence**: `@pmndrs/detect-gpu` — adaptive quality for true device-agnostic immersion
- **AI Emergent Engine**: `@google/genai` (Gemini) — scene generation, particle rules, morphing, lighting, conversational spatial control
- **State**: Zustand
- **Shaders**: `vite-plugin-glsl` + custom GPGPU / fluid systems
- **Extras**: maath, Lenis (smooth spatial scroll)

### Emergent Style Flow
1. User / Gemini prompt → generative scene graph
2. Living particle / liquid systems (GPGPU + instancing)
3. Adaptive materials & lighting based on GPU tier
4. Smooth spatial navigation with physics (Rapier)
5. Glassmorphism + high-end materials that stay calm
